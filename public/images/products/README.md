# 📸 Foto Prodotti — Product Photos

Metti le foto dei prodotti in questa cartella con ESATTAMENTE questi nomi file:

| Nome file richiesto | Prodotto |
|---|---|
| `superior-hazelnut-cream.jpg` | Superior Hazelnut Cream |
| `superior-hazelnut-liqueur.jpg` | Superior Hazelnut Liqueur |
| `superior-red-wine.jpg` | Superior Red Wine |
| `superior-white-wine.jpg` | Superior White Wine |
| `superior-toasted-hazelnut.jpg` | Superior Toasted Hazelnut |
| `placeholder.jpg` | Immagine di fallback (opzionale) |

## Come fare

1. Apri questa cartella sul tuo computer:
   `public/images/products/`

2. Copia le tue foto dentro questa cartella

3. **Rinomina ogni foto** con il nome esatto dalla tabella sopra
   (es. la foto della crema di nocciole deve chiamarsi esattamente `superior-hazelnut-cream.jpg`)

4. I formati supportati sono: `.jpg`, `.jpeg`, `.png`, `.webp`
   (se usi .png o .webp cambia anche l'estensione nel file `src/components/Products.tsx`)

5. Riavvia il server di sviluppo se è già in esecuzione

## Dimensioni consigliate
- **Larghezza:** 600–800px
- **Altezza:** 400–600px
- **Formato:** JPG o WebP per migliori prestazioni
- **Peso max:** 500KB per foto

---

*Place product photos in this folder using exactly the filenames listed above.*
